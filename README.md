# University Forum

A simple forum-style web application for sharing interesting facts and tidbits. Users can browse existing posts and add their own facts through the website.

This project is currently a work in progress as I learn web development and React.

(forum.png)

## Features

- Browse interesting facts and tidbits
- Add new facts through the website
- Organize posts by category _(in progress)_
- Interactive front-end built with React

## Tech Stack

- **React**
- **JavaScript**
- **HTML**
- **CSS**

## Current Status

The front end of the application is currently implemented, including the main forum interface and the ability to create and display new facts.

I am continuing to learn JavaScript and React while developing the project. Future development will include:

- Persisting posts with a database
- Implementing category filtering and organization
- Expanding post interactions
- Improving the overall user experience

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Katieyue/online-forum.git
cd online-forum
npm install
```

Start the development server:

```bash
npm start
```

The application will run locally at `http://localhost:3000`.
